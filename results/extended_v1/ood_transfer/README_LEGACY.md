# LEGACY / PILOT — 3×3 KDD-inclusive OOD transfer (superseded)

This directory holds the **original 3×3 cross-dataset OOD-transfer pilot**
(`monash_electricity_hourly` × `monash_kdd_cup_2018` × `uber_tlc_hourly`, q9, seed 0).
It is kept as an **exploratory / appendix** result and is **not** the headline matrix.

## Why KDD was dropped from the main matrix

KDD Cup 2018 (`monash_kdd_cup_2018`) is **persistence-dominated**: on the same in-context
seasonal-naive denominator (m=24), the trivial **last-value** forecast is *stronger than*
seasonal-naive —

| target | last-value MASE | seasonal-naive m=24 MASE | verdict |
|---|---|---|---|
| electricity | 4.38 | 1.21 | seasonal stronger (healthy) |
| uber | 1.41 | 1.14 | seasonal stronger (healthy) |
| **KDD** | **1.04** | **1.16** | **last-value stronger → persistence warning** |

This is the same warning signal that later disqualified WeatherBench 2 m temperature during
screening. A persistence-dominated, unusually-easy target is a weak setting for the
mid-vs-last-layer question, so KDD is excluded from the headline result on **task-quality**
grounds — decided by the pre-registered screen, not by whether the layerwise result supported
the hypothesis.

## Where the current result lives

The headline is the **4×4** matrix under `results/extended_v2/ood_transfer/`
(electricity, uber_tlc, m4_hourly, wind_farms_hourly; matched 1500/650 budget). The
screen that justified each inclusion is at
`results/extended_v2/ood_transfer/screen/dataset_screen__extended_v2.json`.

Nothing in this legacy directory is regenerated by the `extended_v2` runs (disjoint results
namespace), so these pilot numbers remain frozen for reference.
